# First-bad-state diagnosis

## Reproduction before runtime edits

Actual Brave/Chromium on NVIDIA RTX 4070 WebGL2, approved M6.6 at port 5211. Navigate with `?renderer=webgl&idle=300`, select Deep and seek to the sanctuary, wait for healthy animation. The historical script then blurs focus, changes the query to `idle=1` and dispatches `new Event('pointermove')`. Wait for idle, dismiss with Enter, inspect the returning ocean.

The original script's synthetic event was retained verbatim for failure evidence. Three diagnostic repeats reproduced 22 renderer errors and cyan tissue loss. The exact count differs from the older 18-error report because renderer warnings depend on which corrupted geometry is first bounded/rendered. A fresh control using native CDP `mouseMoved` at (640,450), otherwise the same sequence, produced zero errors and finite geometry before, during and after idle.

Evidence root: `/home/mani/dev/jellyfish-studio/m6-6-1-evidence/`.

## Exact causal chain

1. Generic `Event('pointermove')` arrives with missing `clientX/clientY`. It is untrusted and has no spatial coordinates.
2. `HeroScene.updatePointer` calls `pointerClient.set(undefined, undefined)`; the previous valid values were `[640,450]`. The captured stack points directly to this handler.
3. The next normalization computes `undefined / innerWidth` and `1 - undefined / innerHeight`: both become **NaN**. `pointerNdc`, pointer delta, `pointerGoal`, `currentTarget` and `previousPointer` become non-finite in that same event.
4. The next ordinary animation frame interpolates this invalid target into `current.value`. Exponential decay cannot recover NaN; multiplying it by zero still does not make it a valid number.
5. `JellySchoolDirector.update` consumes that current in desired positions and velocities before tissue updates. Body positions and orientations become invalid. Separately, tissue copies the invalid current to `surfaceCurrent`, which directly enters mantle anchors and appendage integration.
6. The first observed animal is ID 0. Its previous pose, pulse, finite scale `[.9,.9,.9]` and bounded accumulator are valid, but current/body/quaternion are already invalid at tissue entry. The recorded update is frame 44 of the injected trace, delta `0.041666666666666664`, elapsed `2.208900000005961`, journey 1, detail `1.9583333333333333` transitioning toward far tier 0. App idle is **false** and the tab is visible.
7. The first recorded strand corruption is tentacle chain 0, root particle 0, x position. The first uploaded dynamic geometry corruption is tube `position[0]`; oral-arm and bell position buffers subsequently become invalid in the same update chain. Normals/bounds derived from those surfaces are downstream victims. Eventually IDs 0–21 contain invalid dynamic geometry.
8. The renderer later emits `THREE.BufferGeometry.computeBoundingSphere(): Computed radius is NaN. The "position" attribute is likely to have NaN values.`
9. Cyan bell/membrane/tentacle surfaces no longer rasterize normally. Pink internal pieces can remain because their geometry is not generated by the same dynamic surface path. Idle dismissal exposes this damaged scene; it does not initiate the corruption.

The diagnostic scans original and lower-tier bell/arm attributes, tissueSignal, tube/filament geometry, Verlet position/previous state and transforms. Stage logs stop after the first useful chain rather than flooding the console. Scripts are browser-injected tools, not imports in production. Later lifecycle scans additionally check cached bounds, previous/inverse transforms and console warnings.

## Why the correction is at the input boundary

Reject a pointer move unless both coordinates are finite numbers, **before either the UI-drag branch or ordinary branch mutates history**. Do not substitute zero coordinates: that would generate a fictitious current impulse. Valid zero and out-of-viewport coordinates retain their original semantics. Focus/keyboard/activity scheduling remains independent of spatial input.

No per-frame NaN guard or post-upload repair is added. No blanket time reset, clock change, body/Verlet reinitialization or material recreation is justified by this trace. The fix prevents the first bad write; it does not heal an already-corrupted running page. Reload a page that was damaged before installing the fix.
